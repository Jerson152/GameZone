# GameZone 🎮

GameZone es un panel moderno y accesible para tiendas de videojuegos, diseñado para mostrar productos, gestionar inventario y mejorar la experiencia del usuario.

## 🚀 Características
- Diseño responsivo para escritorio y móvil
- Estructura HTML semántica para accesibilidad
- CSS modular para fácil mantenimiento

## 📦 Instalación
```bash
git clone https://github.com/Jerson152/GameZone.git
cd GameZone
npm install
npm start
